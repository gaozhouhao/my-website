# 中英文排版要求

本轮用户要求：画面疏朗、中文字号适度缩小、分节标题不抢眼、长文先整理信息层级。延续米白与紫色，使用偏书刊的视觉节奏。

## 后续内容修改必须遵守

- 中文标题、段落不得出现末行仅剩一两个字的情况。使用 `ReadingText` 输出正文、标题、列表、图注，保留段尾短语；不要通过删减专有名词或缩小到难以阅读来解决。
- `RISC-V`、`ResNet-8`、`2-bit` 等名称保持完整。论文和专利标题必须保留原名。专利英文为 `Miniaturized Low-Pass SSPP Filter Using an Interdigital Structure`。
- 新增文字后重新检查手机、平板、电脑的真实换行。CSS 的 `text-wrap: pretty` 只是辅助，不能作为全部字号、字体和浏览器均无孤字的保证。
- 遇到大段文字，先区分：一句话概述、负责的工作、结果、测试配置。首页展示概述和关键结果；详细过程留在详情页，不把未验证内容写成已完成。
- 文案直接讲工作和成果，不添加自我贬低、免责声明或常识说教。删除“仅抽查”“尚未完成”“不代表”“越少越好”等表达及未完成事项清单。需要交代测试条件时，直接写版本、数量、配置和结果，例如“10 条图样的功能仿真，0 mismatches”。中英文遵循同一原则。
- 分节标题约 22–25 px，中文正文约 14.4–16 px，行距约 1.85–1.95。标题使用 Noto Serif SC 400（经 Next.js 构建后由本站提供字体），正文保留系统无衬线字体。
- 不新增重复的厚重卡片边框、大面积粗黑标题或装饰性技术标签。用留白、细分隔线和稳定对齐表达层级。
- 不隐藏正文来掩盖拥挤；长技术表格和测试配置可以折叠，概述与关键结果直接展示。
- 保留键盘操作、语言切换、手机菜单、原图查看和减少动态效果偏好。
- 每个项目使用一张缩略图，Class AB 使用版图。图片按原比例展示，不用固定高度和内边距把图片缩在米黄色底框中央；详情图与图注分开，不给图片额外添加底色边框。
